# Site institucional

# Objetivo

 Criar um site para apresentar a escola e seus cursos.

# Problemas Identificados

- A escola não possui um site institucional.
- A escola possui pouca visibilidade na internet.
- Pessoas interessadas têm dificuldade para encontrar informações sobre a escola.
- Não existe um canal centralizado para apresentar os cursos, localização e formas de contato.

# Levantamento de Requisitos

## Requisitos Funcionais

- O site deve apresentar informações sobre a escola.
- O site deve apresentar os cursos oferecidos.
- O site deve disponibilizar informações de contato.

## Requisitos não funcionais

- O site deve funcionar em celular, tablet e computador.
- O site deve possuir boa organização visual.
- O carregamento das páginas deve ser rápido.
- O texto deve ser fácil de ler.

## Regras de Negócio

- Os cursos apresentados devem ser aqueles oferecidos pela escola.
- As informações de contato devem ser as informações oficiais da escola.
- Cada curso deve apresentar nome, descrição.
